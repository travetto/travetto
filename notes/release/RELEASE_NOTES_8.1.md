# Travetto 8.1 Release Notes

> [!IMPORTANT]
> **Travetto 8.1** is a major feature release highlighting a comprehensive architectural overhaul of `@travetto/compiler` and the watch pipeline (leveraging TypeScript's incremental `BuilderProgram`, AST dependency tracking, batched change events, and idle-based watcher rotation), model identifier standardization and reflection (`ModelId`, standard UUID generation, and optimized binary SQL storage), native full-text search across all SQL and Elasticsearch providers, conditional test decorators (`@SkipIf` and `@SkipUnless`), Angular documentation generation hooks, and shutdown signal coordination.

## Breaking Changes

* **Schema "View" Concept Removed**: The `@View` decorator and view-specific validation registry in `@travetto/schema` have been removed (`497c30ff62`). Data transformation and sub-schema shapes should now leverage idiomatic TypeScript utility types such as `Pick<T, K>` and `Omit<T, K>`.
* **Model ID Standardization & Generator Removal**:
  * Removed `idSource` from model services and `idGenerator` from `ModelConfig` (`2d4804cf67`, `25794dfa0f`).
  * Removed the `no-generate` configuration and manual ID specification when creating or upserting records. IDs are autogenerated as 32-character hex UUIDs by default unless explicitly supplied (`25794dfa0f`, `7f7a5da18b`).
* **Compiler Watch Events & PID Management**:
  * Deprecated individual `'file'` watch events were removed from `@travetto/compiler` in favor of batched event emissions (`ff8ee7d4f1`, `4149e53fbe`).
  * Replaced `ProcessHandle` and disk pidfiles with in-memory PID tracking and direct IPC communication (`c3243629fa`).
* **Model Indexed Prefix Query Type**: `suggestByIndex` prefix parameter type in `@travetto/model-indexed` was simplified to `string` (`1e32698467`).
* **Web HTTP Development TLS Certificate Generation**: Automatic inline generation of self-signed TLS certificates on server boot was removed. Development certificates are now explicitly generated ahead of time via `trv web:tls-dev` (`8d1cdf6ac1`).

## Compiler Architecture Overhaul (`@travetto/compiler`, `@travetto/manifest`)

* **TypeScript `BuilderProgram` Foundation**: Refactored the compilation pipeline to utilize TypeScript's native incremental `BuilderProgram` (`.tsbuildinfo`) rather than hand-rolled AST caches and custom file hashing (`5f0e1b4d73`, `5830a9c559`).
* **AST Dependency Tracking & Affected Compilation**: Added AST dependency tracking to calculate transitive dependency graphs and compile only affected files during change events (`5830a9c559`, `92b5c65b3d`).
* **Batched Watch Event Pipeline**: Overhauled the file watch pipeline to coalesce raw file changes into 25ms batches, preventing race conditions and redundant recompilation cycles (`4149e53fbe`).
* **Idle-Based Watcher Rotation**: Replaced the previous watch canary with idle-based subscription rotation via `@parcel/watcher` to maintain watch health without polling overhead (`f10b738188`).
* **Configuration & Dependency Soft Resets**: Added automatic soft resets of the watcher upon detecting changes to package manifests (`package.json`, lockfiles) or workspace configurations (`d30be353ee`).
* **Git Worktree Tracking & Automatic Restarts**: Compiler daemon now tracks git worktree changes and automatically clears caches and restarts when git commit / HEAD changes occur (`07fa16c0a8`, `9f7c0dc63e`).
* **In-Memory PID Management**: Removed external `ProcessHandle` and disk-based pidfiles in favor of in-memory PID management and direct IPC communication (`c3243629fa`).
* **Direct Content Comparison**: Removed `naiveHash` in favor of direct content comparison for change detection (`33687c061f`).
* **Inlined Output Paths**: Inlined output path resolution directly, eliminating the overhead of maintaining the `tscOutputFileToOutput` map (`b571f2d128`).
* **Server Listener Tracking & Idle Auto-Shutdown**: Background daemon workflow (`trvc`) tracks active server listeners and automatically shuts down when idle (`1cd96ca137`, `1438f36b1d`, `a0166fccba`).
* **Atomic Manifest File Writes**: Enhanced `@travetto/manifest` with atomic buffered file writes (writing to temporary files and atomically renaming) and output extension helpers (`eed7bf9ff4`).
* **Compiler Logging Decoupled**: Decoupled `IpcLog` from stdout/quiet flags (`TRV_QUIET`) and modernized the compiler logging API (`9355d92be7`, `02e3941297`).
* **Watch Pipeline Stability**:
  * Restored JSX runtime extension rewriting in `#writeOutput` (`953e4cec26`).
  * Excluded dotfiles/hidden directories (`/.`) from watch operations (`708ef8d7e9`).
  * Resolved stale transitive errors across symlinked imports on watch retries (`cfd7c87f41`).
  * Fixed issues where compiler cache clean did not properly restart watch mode (`eaf9acbf0e`).

## Data Modeling & Storage (`@travetto/model-*`, `@travetto/schema`)

### ID Handling & Serialization Overhaul
* **`ModelId` Type Alias & Reflection**: Introduced `ModelId` type alias and `idField` reflection abstraction for primary identifier fields on `@Model` entities (`0e3b1e5b3b`, `cc9453ec3d`).
* **String ID Standardization**: Standardized entity `id` field typing as `string` across models, schemas, and documentation (`7f7a5da18b`).
* **Standardized `@Uuid` Decorator**: Added `@Uuid` decorator and UUID schema specifier in `@travetto/schema` (`0866581e99`).
* **Optimized Binary SQL Storage**: Efficient UUID storage across SQL dialects (`@travetto/model-sql`, `@travetto/model-mysql`, `@travetto/model-postgres`, `@travetto/model-sqlite`), storing IDs as efficient 16-byte binaries or native UUID columns while exposing canonical hex strings to the runtime (`559773feb5`).
* **Plain ID Fallback & Field Generator**: Streamlined ID assignment to fall back to plain identifiers and schema generators, eliminating `idGenerator` and `no-generate` (`25794dfa0f`).

### CRUD Lifecycle & Storage Operations
* **Standardized CRUD Lifecycle Semantics**: Standardized lifecycle hooks, validation steps, and error contracts across all model providers (`1a52297624`).
* **Unified Hook Integration**: Adopted `ModelCrudUtil.preStore`, `preUpdate`, `prePartialUpdate`, and `naivePartialUpdate` across all providers (`1a52297624`).
* **Action-Specific Bulk Hooks**: Adopted action-specific CRUD lifecycle hooks in `ModelBulkUtil` (`b7d0b6723f`).
* **Non-Atomic Provider Support**: Introduced `readBeforeUpdate` configuration flag for storage providers that require pre-read verification (`b830f87ad3`).
* **Partial Type Standardization**: Standardized partial updates on `PartialWithId` (`8b8ea65ea5`).
* **Storage Destruction Safety**: Enforced distinction between DDL destruction (`deleteModel`, `deleteStorage`) and data purge (`truncateModel`).
* **Batch Table Drops**: Added batch table drop performance optimizations in `deleteStorage` across SQL dialects (`ad0dda80a9`).

## Full-Text Search Across Query Providers (`@travetto/model-query`)

* **Unified `$text` Operator**: Introduced `$text` full-text search operator to `@travetto/model-query` and `@travetto/model-query-language` (`ad0dda80a9`).
* **PostgreSQL (`@travetto/model-postgres`)**: Implemented full-text queries utilizing `tsvector`, `to_tsquery`, and GIN indexing (`ad0dda80a9`).
* **MySQL (`@travetto/model-mysql`)**: Implemented full-text queries utilizing `MATCH ... AGAINST ... IN BOOLEAN MODE` and FULLTEXT indexes (`ad0dda80a9`).
* **SQLite (`@travetto/model-sqlite`)**: Implemented full-text search via SQLite `FTS5` virtual tables, synchronization triggers, and multi-statement execution (`ad0dda80a9`).
* **Elasticsearch (`@travetto/model-elasticsearch`)**: Configured text fields with English analyzer and stemming support (`ad0dda80a9`).

## Testing Enhancements (`@travetto/test`)

* **Conditional Test Modifiers (`@SkipIf`, `@SkipUnless`)**: Added suite and test method decorators (`@SkipIf`, `@SkipUnless`) for conditional test execution accepting dynamic predicate functions `(suite) => boolean` (`775fc51764`).
* **Preserve Compiler Artifacts**: Ensured test harness preserves `.trv/output` and `.trv/types` directories during execution (`f7d9ff1f7a`).
* **Parallel Query Suite Execution**: Split model query test suites into individual test files to allow parallel execution across backends (`83dbac1996`).
* **Duration Accuracy**: Fixed missing or inaccurate duration reporting in test execution summaries (`75faa792d0`).

## Web & Runtime (`@travetto/web`, `@travetto/web-http`, `@travetto/runtime`)

* **WHATWG URL Redirect Support**: Updated `WebResponse.redirect()` in `@travetto/web` to accept standard WHATWG `URL` objects in addition to strings (`c7c36b8ec4`).
* **Dedicated TLS Development CLI**: Extracted self-signed development certificate generation from runtime startup into `trv web:tls-dev` (`8d1cdf6ac1`).
* **Shutdown Signal Coordination**: `ShutdownManager.shutdownWithChild` in `@travetto/runtime` coordinates child subprocess exit codes and maps standard POSIX termination signals (SIGINT `130`, SIGTERM `143`) to clean shutdown (`355bb3773b`).
* **Nodemailer Typings**: Resolved typings and compiler integration for `@travetto/email-nodemailer` (`358a06ed71`).

## Code Quality & Linting (`@travetto/lint`, `@travetto/llm-support`)

* **Coercion Ban**: Added lint and maintainer rule forbidding `Boolean()`, `Number()`, and `String()` type coercion in favor of idiomatic operators (`!!value`, `+value`, `${value}` / `value.toString()`) (`8cbd121b57`, `1479c21c74`).
* **Instruction Streamlining**: Streamlined agent and maintainer instructions and gated future additions (`94dd5c249c`).
